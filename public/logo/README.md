# Minkup logo assets

Drop the official **Minkup Media Technology** logo files here, keeping these filenames:

- `minkup-logo-transparent.png` — primary logo, transparent background. Used by Header, Footer, Mobile menu, and favicon.
- `minkup-logo-dark.png` — optional dark-background variant (not currently referenced; add if needed).

The current `minkup-logo-transparent.svg` is a temporary stand-in generated at scaffold time so the site renders during development. Replace it (and point the Header/Footer `siteSettings.logoLight` path at the real PNG) before launch.

Do **not** modify the official logo proportions or colors — sample the exact logo colors into `src/styles/tokens.css` if a brand audit reveals a different hex.
